# 可爱数独乐园

这是一个静态数独游戏网站，使用 HTML、CSS 和 JavaScript 实现，适合儿童玩耍。

## 部署到 GitHub Pages

1. 在 GitHub 上新建一个仓库，例如 `sudoku-game`。
2. 将本地仓库关联到远程仓库：

```bash
git remote add origin https://github.com/你的用户名/sudoku-game.git
git push -u origin main
```

3. 在 GitHub 仓库页面打开 `Settings`。
4. 选择 `Pages`，分支选择 `main`，目录选择 `root`。
5. 保存后即可获得访问链接。

## 访问示例

完成后，你的朋友可以通过类似以下地址访问：

`https://你的用户名.github.io/sudoku-game/`
